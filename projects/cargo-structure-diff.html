PROJECT OVERVIEW

A deterministic CI gate for Rust architecture, published on crates.io. It builds a stable structural IR of a crate, its modules, their relationships and public surface, then diffs that against a baseline and fails the build when the architecture drifts from what was agreed. It turns 'keep the structure clean' from a review-time opinion into an automated, reproducible check, so large refactors and AI-generated changes cannot quietly erode a codebase's shape.

KEY FEATURES

▲

STRUCTURAL DIFF

Compares a crate's module structure against a baseline and flags drift.

▲

DETERMINISTIC

A stable IR so the same code always yields the same verdict.

▲

PUBLISHED

Available on crates.io, installable with cargo install.

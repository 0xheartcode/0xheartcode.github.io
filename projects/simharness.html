PROJECT OVERVIEW

A deterministic, genre-agnostic harness for running and replaying coding agents reproducibly, the eval substrate most agent setups lack. It is built around a discrete-action seam, so the same core drives spatial and non-spatial workers alike, with trace shrinking to reduce a failing run down to its minimal reproduction and porcelain action helpers for writing scenarios. Auto-generated API docs and a one-command quality gate keep it CI-friendly.

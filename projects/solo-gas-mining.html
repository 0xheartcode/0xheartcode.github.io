PROJECT OVERVIEW

Foundry smart contracts implementing a gas, or transaction, mining system for SOLO Chain, which rewards on-chain activity as a mechanism to bootstrap network usage. The contracts are measured with gas-focused test scripts so the incentive maths holds up under real transaction costs, and they ship with deployment tooling and a Foundry test suite.

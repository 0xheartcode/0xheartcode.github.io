PROJECT OVERVIEW

The on-chain contract suite for the MineFun project on SOLO Chain, written with security first. Reentrancy guards and the checks-effects-interactions pattern are applied throughout, with access restrictions on the sensitive entry points. It ships with a deployment pipeline and a TypeScript tooling layer, and a Foundry test suite covering the core flows.

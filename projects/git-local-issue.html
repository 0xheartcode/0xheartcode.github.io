PROJECT OVERVIEW

A distributed, offline-first issue tracker that stores issues natively in Git under refs/issues/*. No external database and no server: issues travel with the repo and sync over ordinary git. Each issue has a permanent UUIDv7 handle with human-friendly display numbers, and the whole tracker ships as a single Rust binary published to crates.io.

KEY FEATURES

▲

GIT-NATIVE

Issues live in refs/issues/*, versioned alongside the code they describe.

▲

OFFLINE-FIRST

Create, edit and close issues with no network and no server.

▲

PUBLISHED

Shipped on crates.io via cargo-dist.

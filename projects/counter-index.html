PROJECT OVERVIEW

A high-throughput OP_NET data indexer: index, store and stream on-chain data. The read-side infrastructure for building on OP_NET, smart contracts on Bitcoin. It ingests blocks, normalizes events and exposes them to downstream services over a routing-aware, read-only surface, so applications can query OP_NET state without each running their own node.

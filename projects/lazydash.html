PROJECT OVERVIEW

A keyboard-driven terminal dashboard for GitHub Projects, written in Go. It gives you multi-repo navigation, a roadmap view, and activity and calendar views derived from issue history, all without leaving the terminal. It can also back its issues with git-local-issue, so the board works fully offline and syncs through Git rather than depending on a hosted service.

PROJECT OVERVIEW

A Rust terminal EVM wallet (externally owned account) that bridges to the browser. It is a cargo workspace with a dedicated vault crate handling keys and signing, a long-running daemon core, and a Google Chrome front end that connects to it, so EVM transactions can be signed and sent from a terminal-first workflow while a familiar browser surface handles interaction. A proof of concept exploring where a wallet's trust boundary should sit.

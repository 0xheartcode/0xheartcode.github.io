PROJECT OVERVIEW

Agentic Developer Workflow: a Python-level abstraction for running structured, repeatable AI agent workflows end to end, with crash-resume so an interrupted run picks up where it left off instead of starting over.

KEY FEATURES

▲

ORCHESTRATION

A run loop split into per-kind step handlers, with convergence signals and architectural gates.

▲

CRASH-RESUME

Idempotent tasks so an interrupted run resumes cleanly rather than latching a stale state.

▲

TOOL INTEGRATION

Uses git-local-issue as an issue sink and cargo-structure-diff as an architectural deep gate.

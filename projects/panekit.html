PROJECT OVERVIEW

A headless terminal-UI output and test harness in Rust (panedrive plus paneview). Drive and assert real TUI state instead of screen-scraping, with crash and false-pass detection for honest CI results.

KEY FEATURES

▲

HEADLESS

Press real keys and read real state from a TUI with no terminal attached.

▲

HONEST RESULTS

CI-grade run results with crash and false-pass detection.

▲

PUBLISHED

Shipped as two crates on crates.io (panedrive and paneview).
